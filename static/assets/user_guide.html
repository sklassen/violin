User Guide: Interactive Violin Plot Demo

Introduction

This application is designed to help you explore and understand different types of statistical distributions and time series data. By adjusting the parameters for each distribution, you can see how they affect the shape of the data and the resulting plots.

The Plots

For each distribution, there are three types of plots:

  • Violin Plot: This plot shows the distribution of the raw data points. The width of the violin represents the density of the data at that point. The box plot inside the violin shows the median, quartiles, and whiskers of the data.
  • Time Series Plot: This plot shows the cumulative sum of the raw data points over time. This helps to visualize the "path" that the data takes.
  • Point & Figure Chart: This is a type of financial chart that shows price movements without regard to time. It is used to identify trends and patterns in the cumulative sum data.

The Distributions

The application allows you to explore five different types of distributions:

Uniform Distribution

This is a simple distribution where all values within a given range are equally likely to occur.

  • Min: The minimum value in the distribution.
  • Max: The maximum value in the distribution.

Normal Distribution

Also known as a "bell curve," this is a very common distribution where the data is centered around a mean value.

  • Mean: The average value of the distribution.
  • Std Dev: The standard deviation, which controls the "spread" of the data.

Skewed Distribution

This is a distribution where the data is not symmetrical. The "skew" parameter controls the direction and degree of the skew.

  • Mean: The average value of the distribution.
  • Std Dev: The standard deviation of the distribution.
  • Skew: A positive value will skew the data to the right, while a negative value will skew it to the left.

Bimodal Distribution

This is a distribution with two "peaks" or modes. It is created by mixing two normal distributions together.

  • Mean 1 & Std Dev 1: The parameters for the first normal distribution.
  • Mean 2 & Std Dev 2: The parameters for the second normal distribution.
  • Weight (Dist 1): This controls the "mix" of the two distributions. A value of 1 will show only the first distribution, while a value of 0 will show only the second.

Fractal Distribution

This distribution is generated using a Fractional Brownian Motion (fBm) algorithm. This creates a time series with "memory," where the next value is influenced by the previous values.

  • Hurst: The Hurst parameter controls the "memory" of the time series.
    • A value of 0.5 indicates a random walk (no memory).
    • A value greater than 0.5 indicates a persistent time series, where an increase is more likely to be followed by another increase.
    • A value less than 0.5 indicates an anti-persistent time series, where an increase is more likely to be followed by a decrease.

Autoregression

The "Autoregression" parameter is available for all distributions except for the fractal distribution. This parameter introduces a relationship between the current value and the previous value in the time series. A higher value will result in a smoother time series.
